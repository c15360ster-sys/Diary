# 일일기록표

9장 운영표 연동 일일/주간/월간 자기관리 기록 앱.

## 기능

- **일일 탭** — 계획/실행표, 우울·불안·수면 기록, 화공 행동 체크, 일과 회고, 내일 첫 행동
- **주간 탭** — 5대 기둥 점수 자동 계산, CEO 회의 질문, 주간 결산
- **월간 탭** — 修身·확인·분석·결정·공유·의미축 점검, 역추적표
- **원칙 탭** — 결론 10가지 실천 원칙
- **루틴 탭** — 아침 시동·ZERO 프로토콜·72시간 게이트
- **상황처방 탭** — 상황별 즉각 처방, 위험 단계 점검, 플랜 B
- **기록 탭** — 최근 30일 기록 열람

## 데이터 저장

Firebase Realtime Database 사용. 오프라인 시 메모리에 임시 보관 후 온라인 복구 시 자동 동기화.
